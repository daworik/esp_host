# ESP-NOW Drone Hive с Веб-Управлением

## 📋 Обзор

Система управления наземными роботами/машинками на базе ESP32 с использованием ESP-NOW для связи и веб-интерфейса для управления через браузер.

### Возможности:
- ✅ **ESP-NOW связь** - быстрая беспроводная связь без WiFi роутера
- ✅ **Шифрование** - защищённая связь с помощью PMK ключа
- ✅ **Веб-интерфейс** - управление через браузер с компьютера/телефона
- ✅ **Телеметрия** - отображение MAC, RSSI, uptime, скорости, статуса
- ✅ **Fail-Safe** - автоматическая остановка при потере сигнала (>1 сек)
- ✅ **Мульти-дрон** - поддержка до 10 агентов одновременно
- ✅ **Heartbeat** - постоянная проверка связи

## 🔧 Настройка

### 1. Узнайте MAC-адреса дронов

Прошейте код агента (`esp_slave`) на ESP32 и откройте Serial Monitor:
```bash
cd /workspace/esp_slave
idf.py -p PORT flash monitor
```
Запишите MAC-адрес из логов (например: `aa:bb:cc:dd:ee:ff`).

### 2. Впишите MAC-адреса в код хоста

Откройте файл `/workspace/esp_master/main/master_drone_controller.c` и найдите строки **48-63**:

```c
// MAC addresses of drones - EDIT THESE WITH YOUR DRONE MAC ADDRESSES
static const uint8_t drone_macs[MAX_DRONES][6] = {
    {0xaa, 0xbb, 0xcc, 0xdd, 0xee, 0xff},  // Drone 1 - ЗАМЕНИТЕ НА ВАШ MAC
    {0x00, 0x00, 0x00, 0x00, 0x00, 0x00},  // Drone 2
    // ... добавьте остальные
};
static uint8_t num_drones_configured = 1;  // Укажите количество дронов (1-10)
```

**Важно:** Измените `num_drones_configured` на фактическое количество ваших дронов!

### 3. Прошейте хост

```bash
cd /workspace/esp_master
idf.py set-target esp32
idf.py -p PORT flash monitor
```

После прошивки вы увидите:
```
I MASTER: WiFi AP started: DroneHive_AP
I MASTER: HTTP server started on http://192.168.4.1
I MASTER: Master controller ready
```

## 🌐 Как использовать веб-интерфейс

1. **Подключитесь к WiFi точке доступа:**
   - SSID: `DroneHive_AP`
   - Пароль: `dronehive123`

2. **Откройте браузер:**
   - Перейдите на `http://192.168.4.1`

3. **Управление:**
   - Выберите дрона из списка или "All Drones" для всех сразу
   - Нажмите кнопки:
     - ⬆ **FORWARD** - движение вперёд
     - ⬇ **BACKWARD** - движение назад
     - ⏹ **STOP** - остановка
     - ⬅ **LEFT** - поворот влево
     - ➡ **RIGHT** - поворот вправо

4. **Статус дронов:**
   - Отображается каждые 2 секунды
   - Показывает: MAC, статус (OK/LOST SIGNAL), RSSI, uptime, скорость, последнюю команду
   - Если дрон потерял сигнал - карточка станет красной

## 🛡 Fail-Safe (Аварийная остановка)

Если агент не получает пакеты от хоста дольше **1 секунды**:
- Моторы автоматически останавливаются
- В логе появляется сообщение: `FAIL-SAFE: Signal lost, stopping motors`
- Статус в веб-интерфейсе меняется на `LOST SIGNAL`

Хост отправляет heartbeat пакеты каждые 500мс для поддержания связи.

## 📡 Команды

### Через веб-интерфейс:
- Кнопки отправляют команды с параметром скорости `1500` (шагов/сек)

### Через UART (Serial):
Формат: `COMMAND [DRONE_ID] [PARAM1] [PARAM2]`

Примеры:
```
forward 0 1500 0    - Все дроны вперёд со скоростью 1500
backward 1 1500 0   - Дрон 1 назад
stop 0              - Остановить все дроны
discover            - Поиск новых дронов
```

## 🧩 Аппаратное подключение

### Для агента (slave):
```
STEP_PIN  -> GPIO 5  (на STEP драйвера)
DIR_PIN   -> GPIO 6  (на DIR драйвера)
MS1_PIN   -> GPIO 12 (на MS1 драйвера)
MS2_PIN   -> GPIO 10 (на MS2 драйвера)
```

### Для хоста (master):
```
LED_PIN   -> GPIO 2  (встроенный LED для индикации)
```

## 🚀 Быстрый старт

1. Прошейте `esp_slave` на одну ESP32 (агент)
2. Скопируйте MAC-адрес из Serial Monitor
3. Вставьте MAC в `esp_master/main/master_drone_controller.c` (строки 52-61)
4. Установите `num_drones_configured = 1`
5. Прошейте `esp_master` на другую ESP32 (хост)
6. Подключитесь к WiFi `DroneHive_AP` / `dronehive123`
7. Откройте `http://192.168.4.1` в браузере
8. Нажимайте кнопки для управления!

---

## 📝 Примечания

- Убедитесь, что обе ESP32 используют **одинаковый ключ шифрования**
- Максимальная дальность ESP-NOW: ~100-200м на открытом пространстве
- Для питания моторов используйте внешний источник (не от ESP32!)
- Веб-интерфейс автообновляется каждые 2 секунды
